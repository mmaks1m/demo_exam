## 1. Назначение раздела

Настоящий раздел позволяет новому пользователю, менеджеру или администратору запустить комплекс «ShoeShop» за минимальное время и выполнить базовые операции без предварительного детального изучения всей технической документации.

> [!TIP]
> Если на вашем рабочем месте еще не установлены Python и PostgreSQL, сначала обратитесь к разделу [Установка и настройка](installation.md).

---

## 2. Пошаговая инструкция запуска комплекса

Для запуска настольного приложения выполните следующие шаги:

### Шаг 1. Открытие терминала в каталоге проекта
Запустите командную строку (PowerShell или CMD) и перейдите в рабочую папку проекта ShoeShop:

```powershell
cd "C:\Users\demia\Desktop\demo\ShoeShop"
```

### Шаг 2. Активация виртуального окружения
Активируйте предварительно настроенное изолированное виртуальное окружение Python:

```powershell
.\.venv\Scripts\Activate.ps1
```

*(В командной строке CMD используйте команду: `.\.venv\Scripts\activate.bat`)*

### Шаг 3. Запуск главного модуля приложения
Выполните команду старта графического контроллера:

```powershell
python main.py
```

После выполнения команды на экране отобразится стартовое окно авторизации **LoginWindow** с фирменной иконкой ShoeShop.

## 3. Демонстрационные учетные записи для входа

Для первичного ознакомления с комплексом в базе данных предусмотрены предварительно настроенные тестовые учетные записи:

| Роль | Логин | Пароль | Доступные полномочия |
|---|---|---|---|
| **Гость** | *Не требуется* | *Не требуется* | Нажмите кнопку **«Войти как Гость»**. Доступен только просмотр каталога обуви без оформления заказов. |
| **Клиент** | `client1` | `client123` | Просмотр каталога, расчет скидок, корзина, оформление заказов, просмотр своих заказов. |
| **Менеджер** | `manager1` | `manager123` | Просмотр всех заказов магазина, смена статуса (в обработке, доставка, готов), выдача по коду. |
| **Администратор** | `admin` | `admin123` | Полный доступ: добавление новых товаров, редактирование цен/скидок/фото, управление заказами. |

> [!WARNING]
> Пароли демонстрационных учетных записей предназначены исключительно для стендового тестирования. При внедрении в промышленную эксплуатацию смените пароли в соответствии с ГОСТ Р 56939-2024!

## 4. Оформление первого тестового заказа (за 2 минуты)

Выполните экспресс-сценарий оформления заказа в роли Клиента:

1. В окне авторизации введите логин `client1`, пароль `client123` и нажмите кнопку **«Войти в систему»**.
2. В открывшемся каталоге выберите интересующую позицию обуви (например, *«Ботинки зимние Classic»*).
3. Воспользуйтесь строкой поиска для фильтрации по бренду или выберите фильтр скидок *«от 10% до 15%»*.
4. Нажмите на карточку товара для просмотра описания и нажмите кнопку **«Добавить в корзину»**.
5. Перейдите во вкладку **«Оформить заказ»**, укажите удобный пункт выдачи из выпадающего списка (`pickup_point`).
6. Нажмите кнопку **«Подтвердить заказ»**. Система автоматически:
   - Рассчитает итоговую стоимость с учетом скидки;
   - Сгенерирует проверочный 3-значный код получения (например, `492`);
   - Зафиксирует заказ со статусом *«Новый»*.
7. Для выхода из профиля нажмите кнопку **«Выйти»** в правом верхнем углу интерфейса.
