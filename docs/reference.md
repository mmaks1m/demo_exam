## 1. Схема и спецификация базы данных

База данных комплекса «ShoeShop» функционирует в СУБД PostgreSQL и включает 5 ключевых реляционных таблиц.

### 1.1. Таблица пользователей (`users`)
Хранит учетные записи, роли и персональные данные сотрудников и покупателей.

| Имя поля | Тип данных | Первичный / Внешний ключ | Описание |
|---|---|---|---|
| `id` | `INTEGER` | PRIMARY KEY (IDENTITY) | Уникальный суррогатный идентификатор пользователя |
| `role` | `VARCHAR(50)` | — | Роль в системе (`Администратор`, `Менеджер`, `Клиент`) |
| `full_name` | `VARCHAR(100)` | — | Фамилия, имя и отчество пользователя |
| `login` | `VARCHAR(100)` | UNIQUE INDEX | Уникальное имя учетной записи для входа |
| `password` | `VARCHAR(100)` | — | Пароль пользователя (хеш / открытый для демо) |

### 1.2. Таблица пунктов выдачи (`pickup_points`)
| Имя поля | Тип данных | Ключ | Описание |
|---|---|---|---|
| `id` | `INTEGER` | PRIMARY KEY (IDENTITY) | Идентификатор пункта выдачи |
| `address` | `VARCHAR(255)` | — | Полный почтовый адрес отделения выдачи |

### 1.3. Таблица номенклатуры товаров (`items`)
| Имя поля | Имя в ORM | Тип данных | Описание |
|---|---|---|---|
| `item_number` | `article` | `VARCHAR(20)` (PK) | Артикул товара (естественный первичный ключ) |
| `name` | `name` | `VARCHAR(100)` | Торговое наименование позиции обуви |
| `unit_measurement`| `unit` | `VARCHAR(20)` | Единица измерения (пара, шт.) |
| `cost` | `price` | `INTEGER` | Базовая стоимость позиции в рублях |
| `provider` | `supplier` | `VARCHAR(100)` | Наименование компании-поставщика |
| `manufacturer` | `manufacturer`| `VARCHAR(100)` | Завод / фабрика-изготовитель |
| `item_category` | `category` | `VARCHAR(50)` | Товарная категория (Туфли, Ботинки, Кроссовки) |
| `current_discount`| `discount` | `INTEGER` | Действующая скидка в процентах (0–99) |
| `quantity_stock` | `stock_quantity`| `INTEGER` | Фактический остаток пар на складе |
| `description` | `description` | `TEXT` | Подробное описание характеристик обуви |
| `photo` | `image_path` | `VARCHAR(255)` | Относительный путь к файлу изображения |

### 1.4. Таблица заказов (`orders`)
| Имя поля | Имя в ORM | Тип данных | Ключ | Описание |
|---|---|---|---|---|
| `order_number` | `id` | `INTEGER` | PRIMARY KEY | Уникальный номер заказа |
| `id_user` | `user_id` | `INTEGER` | FK → `users.id` | Идентификатор клиента |
| `order_date` | `order_date` | `TIMESTAMP` | — | Дата и время формирования заказа |
| `delivery_date` | `delivery_date` | `TIMESTAMP` | — | Плановая дата доставки в пункт выдачи |
| `id_pickup_point`| `pickup_point_id`| `INTEGER`| FK → `pickup_points.id` | Пункт выдачи заказа |
| `receipt_code` | `receive_code` | `INTEGER` | — | 3-значный код получения |
| `order_status` | `status` | `VARCHAR(20)` | — | Текущий статус заказа |

### 1.5. Таблица состава заказов (`orders_items`)
| Имя поля | Тип данных | Ключ | Описание |
|---|---|---|---|
| `order_number` | `INTEGER` | COMPOSITE PK, FK → `orders` | Номер родительского заказа |
| `item_number` | `VARCHAR(20)` | COMPOSITE PK, FK → `items` | Артикул включенного товара |
| `quantity` | `INTEGER` | — | Количество единиц товара в заказе |

## 3. Спецификация конфигурационного файла `.env`

Конфигурационный файл `.env` размещается в корне проекта и загружается модулем `python-dotenv`:

```env
# Имя хоста базы данных (localhost для локальной машины)
DB_HOST=localhost

# Сетевой TCP-порт СУБД PostgreSQL
DB_PORT=5432

# Имя рабочей базы данных
DB_NAME=shoe_shop

# Имя пользователя СУБД с правами SELECT/INSERT/UPDATE/DELETE
DB_USER=postgres

# Пароль пользователя СУБД
DB_PASSWORD=admin
```

## 4. Регламентные SQL-запросы для обслуживания

### 4.1. Проверка доступности базы и целостности связей
```sql
-- Проверка количества активных сессий к базе данных
SELECT count(*) AS active_connections 
FROM pg_stat_activity 
WHERE datname = 'shoe_shop';

-- Выявление записей заказов без корректной ссылки на покупателя
SELECT o.order_number, o.id_user 
FROM orders o 
LEFT JOIN users u ON o.id_user = u.id 
WHERE u.id IS NULL;
```

### 4.2. Сбор статистики и очистка базы
```sql
VACUUM (VERBOSE, ANALYZE) items;
VACUUM (VERBOSE, ANALYZE) orders;
VACUUM (VERBOSE, ANALYZE) orders_items;
```

|---|---|---|
| `Enter` | Окно авторизации | Выполнить вход в систему с текущими данными |
