## 1. Системные требования

Перед установкой и запуском программного комплекса «ShoeShop» убедитесь, что рабочая станция соответствует минимальным техническим требованиям:

| Параметр | Минимальные требования | Рекомендуемые требования |
|---|---|---|
| **Операционная система** | Microsoft Windows 10 (64-bit) / Linux (Ubuntu 20.04+) | Windows 11 (64-bit) Pro / Linux (Ubuntu 22.04 LTS) |
| **Процессор (CPU)** | 2 ядра, от 2.0 ГГц (Intel Core i3 / AMD Ryzen 3) | 4 ядра, от 3.0 ГГц (Intel Core i5 / AMD Ryzen 5) |
| **Оперативная память (RAM)** | 4 ГБ | 8 ГБ и более |
| **Свободное дисковое пространство** | 1.5 ГБ (приложение + зависимости) | 5.0 ГБ (с учетом базы данных и медиафайлов) |
| **Разрешение монитора** | 1280 × 720 (HD) | 1920 × 1080 (Full HD) |
| **Версия Python** | Python 3.10.x | Python 3.11.x (64-bit) |
| **СУБД** | PostgreSQL 14.x | PostgreSQL 16.x / 18.x |
| **Сетевое подключение** | Локальный доступ к localhost:5432 | Локальная сеть 100/1000 Мбит/с с latency < 5 мс |

> [!IMPORTANT]
> Комплекс требует обязательного наличия установленного интерпретатора Python архитектуры x64. Использование 32-битных сборок может приводить к конфликтам с бинарными библиотеками PySide6.

## 2. Развертывание виртуального окружения Python

Рекомендуется изолировать зависимости приложения от глобального окружения операционной системы.

### Шаг 1. Создание виртуального окружения
В корневой папке проекта выполните команду создания среды:

```powershell
python -m venv .venv
```

### Шаг 2. Активация окружения
```powershell
.\.venv\Scripts\Activate.ps1
```

### Шаг 3. Обновление пакетного менеджера pip
```powershell
python -m pip install --upgrade pip
```

## 3. Установка программных зависимостей

Комплекс ShoeShop использует следующие ключевые библиотеки:
- `PySide6` — официальные биндинги Qt 6 для создания графического интерфейса;
- `SQLAlchemy` (v2.0+) — объектно-реляционное отображение (ORM);
- `psycopg2-binary` — высокопроизводительный драйвер взаимодействия с СУБД PostgreSQL;
- `python-dotenv` — загрузка конфигурационных переменных из файла `.env`;
- `Pillow` — обработка, масштабирование и кэширование каталожных изображений обуви.

Установите все зависимости одной командой:

```powershell
pip install PySide6 SQLAlchemy psycopg2-binary python-dotenv Pillow
```

Проверьте корректность установки пакетов:

```powershell
pip list
```

## 4. Развертывание и инициализация базы данных PostgreSQL

Комплекс функционирует под управлением СУБД PostgreSQL.

### Шаг 1. Проверка активности службы PostgreSQL
В PowerShell выполните команду проверки статуса службы:

```powershell
Get-Service -Name "postgresql*"
```

Убедитесь, что служба находится в состоянии `Running`.

### Шаг 2. Создание базы данных и пользователя
Запустите интерактивную консоль СУБД `psql` под учетной записью суперпользователя:

```powershell
psql -U postgres
```

В консоли СУБД выполните следующие SQL-инструкции:

```sql
-- 1. Создание базы данных для комплекса ShoeShop
CREATE DATABASE shoe_shop
    WITH 
    ENCODING = 'UTF8'
    LC_COLLATE = 'Russian_Russia.1251'
    LC_CTYPE = 'Russian_Russia.1251'
    TABLESPACE = pg_default
    CONNECTION LIMIT = -1;

-- 2. Подключение к созданной базе данных
\connect shoe_shop;

-- 3. Создание таблиц (при необходимости ручной инициализации)
-- (При первом старте приложения SQLAlchemy способна создавать структуру автоматически через Base.metadata.create_all)
```

### Шаг 3. Импорт демонстрационного дампа данных
Если у вас имеется файл дампа `backup.sql`, восстановите данные:

```powershell
psql -U postgres -d shoe_shop -f backup.sql
```

## 5. Конфигурация файла параметров `.env`

В соответствии с требованиями стандартов безопасной разработки (ГОСТ Р 56939-2024, ГОСТ Р 58412-2019) все учетные данные и параметры подключения к СУБД изолированы в конфигурационном файле `.env`, расположенном в корневой директории проекта.

Создайте или отредактируйте файл `.env`:

```env
# Параметры подключения к серверу PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=shoe_shop
DB_USER=postgres
DB_PASSWORD=admin
```

### Спецификация параметров конфигурации:

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `DB_HOST` | Сетевой адрес хоста сервера СУБД | `localhost` (или `127.0.0.1`) |
| `DB_PORT` | Сетевой порт службы PostgreSQL | `5432` |
| `DB_NAME` | Имя целевой базы данных комплекса | `shoe_shop` |
| `DB_USER` | Имя пользователя базы данных | `postgres` |
| `DB_PASSWORD` | Пароль учетной записи СУБД | Задается администратором |

> [!WARNING]
> Файл `.env` содержит конфиденциальные учетные данные. Никогда не включайте его в публичные репозитории Git (добавьте `.env` в файл `.gitignore`)!

## 6. Проверочный запуск и валидация установки

Для подтверждения успешности развертывания выполните контрольный пуск:

```powershell
python main.py
```

Критерии успешной установки:
- Отсутствуют ошибки трассировки `traceback` в окне консоли;
- На экране отобразилось окно авторизации с активными полями ввода;
- При нажатии на кнопку «Войти как Гость» открывается каталог обуви с миниатюрами позиций.
