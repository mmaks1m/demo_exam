## 1. Типовые неисправности и алгоритмы их устранения

В данном разделе приведены наиболее распространенные сбои, возникающие при эксплуатации программного комплекса «ShoeShop», и четкие инструкции по их локализации и устранению.

---

### Проблема 1: Ошибка подключения к базе данных (`OperationalError: could not connect to server`)

> [!WARNING]
> При запуске приложения `main.py` консоль выдает ошибку `psycopg2.OperationalError: connection to server at "localhost", port 5432 failed`. Окно входа не открывается либо зависает.

**Причины неисправности:**
1. Служба PostgreSQL не запущена в операционной системе Windows;
2. Неверно указаны параметры авторизации (порт, пользователь, пароль) в файле `.env`;
3. Порт 5432 заблокирован локальным брандмауэром или занят сторонней службой.

**Порядок устранения:**
1. Откройте консоль PowerShell от имени администратора и перезапустите службу:
   ```powershell
   Restart-Service -Name "postgresql*"
   ```
2. Проверьте прослушивание порта 5432:
   ```powershell
   Test-NetConnection -ComputerName localhost -Port 5432
   ```
   *Параметр `TcpTestSucceeded` должен иметь значение `True`.*
3. Проверьте правильность пароля в файле `.env`, попробовав подключиться вручную через утилиту `psql`:
   ```powershell
   psql -U postgres -h localhost -d shoe_shop
   ```

---

### Проблема 2: Ошибка импорта модулей `ModuleNotFoundError: No module named 'PySide6'`

**Причина:** Приложение запущено без предварительной активации изолированного виртуального окружения Python.

**Порядок устранения:**
1. Активируйте виртуальное окружение проекта:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
2. Если библиотеки не были установлены, выполните пакетную установку:
   ```powershell
   pip install PySide6 SQLAlchemy psycopg2-binary python-dotenv Pillow
   ```

---

### Проблема 3: Отсутствие изображений товаров в карточках каталога

**Причина:** Графические файлы `.jpg` отсутствуют в папке `resources/images/`, либо в базе данных указано некорректное имя файла.

**Порядок устранения:**
1. Убедитесь в наличии каталога `resources/images/` в корне проекта;
2. Проверьте права на чтение файлов в данной директории;
3. Для позиций без изображений комплекс автоматически загружает стандартную заглушку `Icon.png`.

## 2. Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Вопрос 1: Можно ли запустить комплекс без установленной СУБД PostgreSQL?</b></summary>
<br>
<i>Ответ:</i> Нет, комплекс спроектирован для работы с промышленной клиент-серверной СУБД PostgreSQL 14+. Без доступного сервера СУБД невозможно хранение номенклатуры, учет заказов и авторизация пользователей.
</details>

<details>
<summary><b>Вопрос 2: Как сбросить пароль администратора, если он был утерян?</b></summary>
<br>
<i>Ответ:</i> Администратор базы данных может сбросить пароль непосредственно через SQL-консоль <code>psql</code>:
<pre><code>UPDATE users SET password = 'new_password' WHERE login = 'admin';</code></pre>
</details>

<details>
<summary><b>Вопрос 3: Поддерживается ли работа нескольких пользователей одновременно?</b></summary>
<br>
<i>Ответ:</i> Да. Благодаря архитектуре клиент-серверной базы данных PostgreSQL и пулу соединений SQLAlchemy комплекс поддерживает одновременную работу множества рабочих мест операторов и клиентов в локальной сети предприятия.
</details>

<details>
<summary><b>Вопрос 4: Как настроить удаленное подключение к серверу СУБД?</b></summary>
<br>
<i>Ответ:</i> В файле <code>.env</code> клиентского терминала измените значение параметра <code>DB_HOST</code> с <code>localhost</code> на фактический IP-адрес сервера в локальной сети (например, <code>DB_HOST=192.168.1.50</code>). Убедитесь, что на сервере в файле <code>pg_hba.conf</code> разрешены входящие подключения для подсети.
</details>

<details>
<summary><b>Вопрос 5: Где хранятся загружаемые администратором фотографии обуви?</b></summary>
<br>
<i>Ответ:</i> Фотографии сохраняются в локальный каталог <code>resources/images/</code> рабочей станции или сетевого файлового хранилища, а в таблице <code>items</code> базы данных сохраняется только относительное имя файла (например, <code>1.jpg</code>).
</details>
