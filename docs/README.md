## 🧭 Навигация по документации

Интерактивная документационная система комплекса «ShoeShop» спроектирована по концепции *Docs-as-Code* с использованием синтаксиса Markdown. Все разделы образуют единую связанную информационную среду с перекрестной навигацией:

- 🏠 **[Главная страница](index.md)** — портал документации, обзор назначения системы, ключевые возможности, архитектура комплекса и схема экранных форм;
- ⚡ **[Быстрый старт](quick-start.md)** — руководство по первому запуску, тестовые учетные записи, оформление заказа за 2 минуты;
- ⚙️ **[Установка и настройка](installation.md)** — системные требования, пошаговое развертывание окружения Python 3.11, настройка СУБД PostgreSQL 14+, конфигурация `.env`;
- 📖 **[Руководство пользователя](user-guide.md)** — детальный регламент работы пользователей и сотрудников (Гость, Клиент, Менеджер, Администратор);
- 📚 **[Справочная информация](reference.md)** — структура и связи таблиц БД, спецификация параметров конфигурации, перечень SQL-запросов и горячих клавиш;
- 🛠️ **[Диагностика и FAQ](troubleshooting.md)** — выявление и устранение типовых сбоев, решение проблем с СУБД и библиотеками, ответы на частые вопросы.

## 🖥️ Способы просмотра документации

1. **В среде Visual Studio Code:**
   - Откройте директорию `interactive-documentation/` в VS Code;
   - Откройте любой файл (например, `index.md`) и нажмите комбинацию клавиш `Ctrl + Shift + V` (или `Ctrl + K, V`) для включения интерактивного режима предварительного просмотра с поддержкой перехода по гиперссылкам.
2. **В веб-репозитории (GitHub / GitLab):**
   - Все Markdown-файлы корректно визуализируются сервером репозитория, обеспечивая бесшовные переходы между тематическими страницами по относительным ссылкам.
3. **Через генератор статической документации MkDocs:**
   - При наличии установленного пакета `mkdocs` выполните команду `mkdocs serve` для локального запуска веб-версии портала по адресу `http://127.0.0.1:8000`.
