Учебный проект: десктопное приложение для просмотра каталога обуви, фильтрации и оформления заказов с разграничением прав доступа.

## Возможности
- **Каталог товаров:** просмотр полного списка моделей обуви с отображением цены, действующей скидки, категории и статуса наличия на складе;
- **Поиск и фильтрация:** динамический поиск по наименованию и описанию, фильтрация по категориям/поставщикам, сортировка по стоимости;
- **Авторизация:** разграничение ролей пользователей (Клиент, Менеджер, Администратор) и гостевой режим;
- **Корзина и оформление заказа:** добавление позиций, выбор пункта выдачи, расчет итоговой стоимости с учетом персональных скидок, генерация талона заказа;
- **Управление заказами:** просмотр истории заказов, изменение статусов («Новый», «В обработке», «Завершен»), редактирование состава заказа (для менеджера и администратора).

## Требования
- Python 3.10 или выше
- СУБД PostgreSQL 14 / 15 / 16
- Библиотеки и зависимости, указанные в файле `requirements.txt`

## Установка и запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/mmaks1m/demo_exam.git
   cd demo_exam
   ```

2. **Создать и активировать виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Linux/macOS:
   source venv/bin/activate
   ```

3. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Развернуть базу данных PostgreSQL:**
   - Создайте базу данных `shoe_store` (или `session`) в pgAdmin / psql:
     ```sql
     CREATE DATABASE shoe_store;
     ```
   - Загрузите структуру и тестовые данные из скрипта:
     ```bash
     psql -U postgres -d shoe_store -f database/shoe_store.sql
     ```

5. **Настроить подключение:**
   Скопируйте файл с примером настроек и укажите свои параметры подключения:
   ```bash
   copy config.ini.example config.ini
   ```
   В файле `config.ini` укажите реальные параметры вашей СУБД (host, port, name, user, password).

6. **Запустить приложение:**
   ```bash
   python main.py
   ```

## Схема базы данных (ER-диаграмма)
В проекте используется реляционная база данных PostgreSQL. Структура БД включает следующие основные сущности:
- `users` — пользователи системы (клиенты, менеджеры, администраторы) с хэшированными паролями;
- `roles` — справочник ролей пользователей;
- `products` — каталог обуви (артикул, наименование, стоимость, скидка, производитель, поставщик, остаток на складе);
- `orders` — заказы клиентов (дата оформления, дата доставки, пункт выдачи, код получения, статус заказа);
- `order_items` — состав заказа (перечень позиций и количество единиц каждого товара);
- `pickup_points` — справочник пунктов выдачи заказов.

Графическая схема представлена в файле [`docs/er_diagram.pdf`](docs/er_diagram.pdf), а также в растровом формате [`docs/images/scheme.png`](docs/images/scheme.png).
